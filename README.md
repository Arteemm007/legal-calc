# Юридический калькулятор долей недвижимости

Веб-приложение для юристов и риелторов, предназначенное для быстрого и точного расчета долей в праве общей долевой собственности. Разработано для автоматизации сложных расчетов при работе с **материнским капиталом (МСК)** и сделками, требующими согласования с **органами опеки и попечительства**.

Инструмент полностью исключает человеческий фактор, защищает от ошибок в расчетах долей (вплоть до копеек и квадратных миллиметров) и формирует юридически чистые дроби, понятные для нотариусов, Росреестра и СФР.

---

## 🛠 Стек технологий
* **Backend:** Python 3.11, FastAPI, Pydantic, Fractions
* **Frontend:** HTML5, TailwindCSS (CDN), Vanilla JavaScript
* **Инфраструктура:** Docker, Docker Compose
* **Архитектура:** Монолитное SPA с REST API бэкендом (легко встраивается как виджет в CRM или используется автономно).

---

## 🚀 Основные возможности

1. **Модуль «МСК» (Материнский капитал):**
   * Расчет минимальной доли каждого члена семьи пропорционально сумме МСК.
   * Учет стоимости объекта и количества членов семьи.
   * Автоматический перевод доли в квадратные метры (на основе общей площади).
   * Генерация форматов для договора: стандарт ЕГРН (сотые/тысячные), расчет по площади и простая дробь.
   * Функция копирования готовых формулировок для текста ДКП в один клик.

2. **Модуль «Опека» (Встречная сделка):**
   * Расчет имущественных прав несовершеннолетнего при продаже старого объекта и покупке нового.
   * Проверка соблюдения двух обязательных условий опеки: **не уменьшение площади** (в кв. м) и **не уменьшение стоимости** (в рублях).
   * Функция «Запас прочности» (+1 м² к старой площади ребенка) для повышения лояльности инспекторов опеки.
   * Алгоритм строгого округления вверх с подбором компактных двузначных дробей (например, `4/71`, `22/41`), предотвращающий уменьшение долей.

3. **Интерфейс и UX:**
   * Строгий корпоративный дизайн в стиле Tech-Minimalism (светлая тема, карточная верстка).
   * Автоматическое форматирование денежных сумм с разделителями тысяч (например, `6 870 000 ₽`).
   * Защита от ошибок ввода (автоматическая конвертация запятых в точки в полях площади).

## ⚙️ Инструкция по локальному запуску

### Вариант 1: Через Docker (Рекомендуется)
Убедитесь, что у вас установлены Docker и Docker Compose. В корне проекта выполните:
```bash
docker-compose up -d --build

После запуска калькулятор будет доступен в браузере по адресу: http://localhost:8000

Вариант 2: Запуск вручную через Python (для разработки)
Создайте и активируйте виртуальное окружение:

Bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate
Установите зависимости:

Bash
pip install -r requirements.txt
Запустите сервер разработки:

Bash
uvicorn main:app --reload
Откройте в браузере: http://127.0.0.1:8000
